# 인제생

인제대학교 학생을 위한 비공식 캠퍼스 생활 도우미입니다.
학교 계정 로그인 없이 학식, 셔틀버스, 공지, 학사일정을 한곳에서 볼 수 있습니다.

**바로가기: [ijs.megabrain.kr](https://ijs.megabrain.kr/)**

- [학식](https://ijs.megabrain.kr/campus/meals): 다인·모인 식단과 운영 안내
- [셔틀버스](https://ijs.megabrain.kr/campus/shuttle): 다음 출발 시간과 전체 시간표
- [공지사항](https://ijs.megabrain.kr/campus/notices): 학교·학과 공지 모아보기
- [학사일정](https://ijs.megabrain.kr/campus/calendar): 월별 학교 일정
- [캠퍼스 지도](https://ijs.megabrain.kr/campus/map): 건물 위치와 층별 시설
- [열람실](https://ijs.megabrain.kr/campus/library): 남은 좌석 확인
- [인제생 AI](https://ijs.megabrain.kr/ai): 학교 공개 자료 기반 질문과 답변

> 학생이 만든 비공식 프로젝트이며 인제대학교와 관계가 없습니다.
> 정확한 정보는 학교 공식 채널에서 확인해 주세요.
